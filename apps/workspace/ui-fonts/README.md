# UI fonts

Plus Jakarta Sans variable normal, from `@fontsource-variable/plus-jakarta-sans@5.3.0`, licensed under the included SIL Open Font License (`OFL.txt`). The npm tarball integrity, individual SHA-256 hashes, lengths and Unicode ranges are pinned in `manifest.json`. The tarball was checked against the npm integrity value before selecting these files.

Four WOFF2 subsets total 59,144 bytes. The primary Latin subset is 27,348 bytes; the browser requests additional subsets only for matching characters. No font service or new runtime dependency is needed.

`node build-ui-fonts.mjs` validates the license, bytes, hashes and WOFF2 signatures, enforces a 100 KiB combined budget, then generates the ignored `ui-font-assets.generated.mjs`. Build/test/dev hooks run this alongside the separate contract font build. Generated bytes are embedded in the Worker and decoded on demand. Routes include a content hash, require the same authenticated active actor as the UI and use private immutable caching. CSP permits same-origin fonts only.

To update, select an explicit upstream version, verify its package integrity and license, update all asset hashes/ranges, then run build and API/browser verification. Do not edit generated output. The PDF fonts in `contract-fonts/` serve a separate document-rendering requirement and are not interchangeable with these UI fonts.
